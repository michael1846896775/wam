项目概括：针对传统植物表型测量依赖人工、效率低的问题，开展基于视频序列的三维重建与自动化表型提取研究。
▪ 全流程搭建：从零设计并搭建植物三维重建全流程软件，规划"视频抽帧-参数估计-语义分割-稠密重建-表型提取"完整算法链路。

▪ 难点攻关：针对原始代码仅支持 Linux 的兼容性限制，通过 WSL 在 Windows 端成功搭建 Linux 运行环境并完成代码复现；
初期补齐相机内外参成像原理，结合论文阅读与代码调试，将单视频最佳处理时长控制在 30s~1min、单视频处理耗时约 3 分钟。

▪ 算法实现与验证：基于 VGGSfM 获取每帧图像内外参数及初始点云，引入 SAM2 进行植株主体与背景的语义分割，采用 3D 高
斯稠密重建生成结果点云并开展表型参数提取，对来自海南、湖北、陕西等多地区玉米、小麦、水稻植株完成三维重建验证。

▪ 软件封装与落地：开发 Python GUI 桌面软件，用户导入视频即可自动输出点云，已在至少 3 台设备部署并收集反馈。
项目成果：成功对海南、湖北、陕西等多地区玉米、小麦、水稻植株完成重建验证，开发 Python GUI 工具并在多台设备部署落地。
